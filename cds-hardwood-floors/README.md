# CDS Hardwood Floors

Production marketing website for **CDS Hardwood Floors** — hardwood floor
refinishing, sanding, screen-and-coat, and installation in Montgomery County, MD.

- **Phone:** (240) 731-7030 · MHIC licensed & insured · veteran discount
- **Stack:** Next.js 16 (App Router, TypeScript, Tailwind v4)
- **Deploy target:** Cloudflare Workers via [`@opennextjs/cloudflare`](https://opennext.js.org/cloudflare)

## Architecture

Server-rendered, crawlable HTML for SEO. The cinematic WebGL (added in later
phases) is isolated into a single client-only island so it never blocks LCP or
crawling — the LCP element is the static poster `public/renders/master.jpg`.

```
app/
  layout.tsx                 Root layout, fonts, metadataBase, LocalBusiness JSON-LD
  page.tsx                   Home
  services/                  Services index + [service] (generateStaticParams)
  service-area/              Area index + [area] (generateStaticParams)
  contact/                   Contact + estimate form
  api/estimate/route.ts      Turnstile verify + Resend email
  sitemap.ts / robots.ts     SEO routes
components/                  UI, Header/Footer, Hero, BeforeAfter, EstimateForm
lib/                         site config, services, areas, JSON-LD, metadata, image loader
```

### SEO

- `generateMetadata` per page with canonical URLs and Open Graph.
- `HomeAndConstructionBusiness` (LocalBusiness) JSON-LD site-wide, plus `Service`,
  per-area business, and `BreadcrumbList` structured data.
- `sitemap.xml` and `robots.txt` generated from the route data.

## Environment

Public (build-time) — copy `.env.example` → `.env.local`:

- `NEXT_PUBLIC_SITE_URL` — canonical origin (no trailing slash)
- `NEXT_PUBLIC_TURNSTILE_SITE_KEY` — Cloudflare Turnstile public key

Secrets — copy `.dev.vars.example` → `.dev.vars` for local; in production set as
Worker secrets (`wrangler secret put <NAME>`):

- `TURNSTILE_SECRET_KEY`
- `RESEND_API_KEY`
- `ESTIMATE_TO_EMAIL`, `ESTIMATE_FROM_EMAIL`

## Assets

`public/renders/{master,before,after}.jpg` and
`public/textures/{oak,maple,walnut,hickory}.jpg` are currently **labeled
placeholders** generated by `scripts/gen-placeholders.mjs`. Drop the real
renders/textures in at the same paths to replace them.

## Cloudflare config

- `wrangler.jsonc` — `nodejs_compat`, `ASSETS` + `IMAGES` bindings.
- `open-next.config.ts` — OpenNext Cloudflare adapter config.
- `lib/cf-image-loader.ts` — custom `next/image` loader (Cloudflare Image Resizing).
